# syosetu-scraper

syosetu-scraper 是一款基于 Python 开发的自动化脚本，旨在将日本 syosetu 小说网站上的作品抓取并打包为格式规范的 EPUB 电子书。

## 环境准备

在运行本程序前，请确保你的电脑上已经安装了 Python 3.10 或更高版本。

安装必要依赖，请打开你的命令行终端（Terminal/CMD/PowerShell），进入保存脚本的文件夹，运行以下命令安装所需的 Python 库：

```bash
python -m pip install aiohttp beautifulsoup4 ebooklib tqdm
```

## 使用方法

有三种运行方式：
* 交互式运行：`python syosetu_scraper.py`，程序会提示输入 N-code ID 或完整 URL。
* 直接传入 N-code：`python syosetu_scraper.py n3170ed`。
* 传入完整 syosetu URL：`python syosetu_scraper.py https://ncode.syosetu.com/n3170ed/`。

如果你所在环境需要代理，可通过第二个参数指定代理地址：

```bash
python syosetu_scraper.py n3170ed http://127.0.0.1:7897
```

脚本也会自动读取环境变量中的代理设置：

* `HTTP_PROXY`
* `HTTPS_PROXY`
* `http_proxy`
* `https_proxy`

> 代理模式下脚本会禁用 SSL 证书验证，以兼容常见的本地 HTTP 代理。请确保代理来源可信。

生成的 EPUB 文件会保存到当前运行目录，文件名来自小说标题，自动过滤非法文件名字符。

## 排版特性说明
本工具生成的 EPUB 文件经过深度优化，默认包含以下排版规范：
* 首行缩进：每个自然段落首行自动缩进 2 个字符宽度（使用 CSS text-indent）。
* 段落间距：段落之间保持单行高度（1em），阅读体验清晰。
* 标题规范：章节标题居中，并与正文保持适当空行。

## 常见问题排查 (FAQ)
Q：为什么我打开书后，排版非常乱，没有缩进或间距？

A：这种情况通常不是 EPUB 文件的问题，而是阅读器本身的样式或显示设置导致的。你可以在阅读器中关闭自定义 CSS 或使用其他阅读器验证文件。

---

Q：为什么下载速度很慢？

A：本脚本采用了异步并发下载机制，而不是传统多线程。即便如此，目标网站可能仍会对短时间内的请求数量进行限制。此外，代理链、网络环境和章节数量也会影响总耗时。

---

Q：程序报错显示“未找到正文”？

A：这可能是因为目标网页结构已变化，或者该章节需要登录/年龄验证（R18）才能访问。当前脚本会在捕获到该错误后将该章节内容置为空，并在 EPUB 中显示错误提示。

---

Q：代理模式下提示连接失败或 SSL 证书错误怎么办？

A：脚本已支持通过 `http://127.0.0.1:7897` 等本地代理连接，并会在代理模式下自动禁用 SSL 证书验证。若仍然报错：
* 确认代理地址和端口是否正确，且代理服务正在运行。
* 确认代理支持 HTTPS 代理请求。
* 若使用 HTTP 代理且目标网站为 HTTPS，请使用 `http://` 开头代理地址。
* 若代理服务本身要求认证，脚本目前不支持代理用户名/密码。
