# syosetu-scraper

syosetu-scraper 是一款基于 Python 开发的自动化脚本，旨在将日本 syosetu 小说网站上的作品抓取并打包为格式规范的 EPUB 电子书。

## 环境准备

在运行本程序前，请确保你的电脑上已经安装了 Python 3.8 或更高版本。

安装必要依赖，请打开你的命令行终端（Terminal/CMD/PowerShell），进入保存脚本的文件夹，运行以下命令安装所需的 Python 库：

```Bash
pip install requests beautifulsoup4 ebooklib tqdm
```

## 使用方法

有两种运行方式：
* 方式一：直接运行（交互式）。双击运行脚本，或在终端输入：`python syosetu_scraper.py`，程序会提示输入 N-code ID。
* 方式二：命令行参数运行（快捷式）。`python syosetu_scraper.py N-code`。

## 排版特性说明
本工具生成的 EPUB 文件经过深度优化，默认包含以下排版规范：
* 首行缩进：每个自然段落首行自动缩进 2 个字符宽度（使用 CSS text-indent）。
* 段落间距：段落之间保持单行高度（1em），阅读体验清晰。
* 标题规范：章节标题居中，并与正文保持适当空行。

## 常见问题排查 (FAQ)
Q：为什么我打开书后，排版非常乱，没有缩进或间距？

A：这种情况通常不是 EPUB 文件的问题，而是阅读器本身的设置导致的。

---

Q：为什么下载速度很慢？

A：本脚本采用了多线程下载机制。如果速度依然慢，通常是因为该小说章节数量巨大，且目标网站为了防抓取会对并发连接进行频率限制。脚本已内置了超时重试机制，请耐心等待。

---

Q：程序报错显示“未找到正文”？

A：这可能是因为目标网站的网页结构发生了变动。请检查该网页是否开启了年龄验证（R18）或需要特殊权限访问。如果网页本身内容无法解析，脚本会跳过该章节并在终端提示错误。
